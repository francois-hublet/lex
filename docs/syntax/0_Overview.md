# Lex Technical Manual

## General remarks

### Case and indentation

The Lex language is case and indentation-sensitive. The number of spaces introducing each indentation level is free, but must be consistent throughout the code. As a rule of thumb, we suggest using four spaces for each identation level.

### Statements

Lex programs are sequences of statements separated by line breaks. A statement starts with no indentation and can be one of the following:

1. An import statement (see [Imports](1_Imports.md))

2. A section label (see [Labels](2_Labels.md))

3. A type declaration (see [Types](3_Types.md))

4. A function declaration (see [Functions](4_Functions.md))

5. An event declaration (see [Events](5_Events.md))

6. A rule declaration (see [Rules](6_Rules.md))

7. A comment (see [Comments](7_Comments.md))
